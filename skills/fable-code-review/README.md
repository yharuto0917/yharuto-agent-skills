# Fable Code Review Skill

コードを「評価」する局面で使う判断の型・ヒューリスティクス・検証戦略を提供するAIエージェント向けのスキルです。
このスキルは単純なチェックリストではなく、未知のコードに対する嗅覚と、その疑いを証拠で確定または棄却する推論プロセスをAIに与えます。

「レビューして」「このコードどう思う」「diffを見て」「PRを確認して」「セキュリティ監査して」「リファクタすべき点を挙げて」など、コードの正しさ・安全性・設計・保守性を判断するあらゆる場面で活用できます。

## インストール方法

このスキルは、`npx` コマンドまたは `gh skill` コマンドを使用してご自身の環境に追加することができます。

### `npx` を使用する場合

```bash
npx skills add yharuto0917/fable-code-review
```

### `gh skill` を使用する場合

```bash
gh skill install yharuto0917/fable-code-review fable-code-review
```

## スキルの特徴と判断の型

このスキルは以下のフェーズに沿って、AIによるコードレビューの品質を向上させます。

1. **読み始める前（オリエンテーション）**: 全体像の把握、異常の検出、検証の当たりをつけるアプローチ。
2. **パターン認識（精読とスキップ）**: どこを注意深く読み、どこを読み飛ばしてよいかのシグナル判断。
3. **疑い → 検証 → 判定**: 単なる推測で終わらせず、コードの使われ方や実データに基づいて仮説を検証・棄却するプロセス。
4. **見落としを防ぐチェック観点**: ロジック、セキュリティ、データ整合性（並行性）、エラーハンドリングなどの多角的なチェック。
5. **指摘の重み付けと取捨選択**: 損害の大きさと発生確率（severity）に基づいた、レビュイーにとって価値のある指摘の選別。
6. **不確実性の扱い**: AI自身が確証を持てない場合に、断定を避けて調査のヒントを残すアプローチ。
